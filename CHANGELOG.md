# Changelog

## 0.1.0
- First version: one GM dashboard that detects the active Warhammer system (WFRP 4e/5e, The Old World, Imperium Maledictum, Wrath & Glory, Soulbound).
- **Session** tab: award XP with a reason, restore the system's resource (Fortune, Fate, Wrath, Soulfire), end-of-session routine (chat export and clearing, XP, resource, holding scene, session number, summary).
- **Group Test** tab: secret tests for several characters with the system's own skills, difficulty and roll dialog, and one summary for the GM.
- Each tab can be switched off in the settings.
- Tested with Foundry v14 and WFRP4e 10.1.2 (4e rules).
